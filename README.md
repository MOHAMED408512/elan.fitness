# Élan Fitness - Site Web Multipage

## Description du Projet
Ce projet consiste en la migration du site web de la salle de sport Élan Fitness (Casablanca) d'un format one-pager vers un site multipage complet. L'objectif est d'améliorer la présence en ligne de la salle, d'offrir une navigation claire et fluide, et d'assurer une expérience utilisateur optimale sur tous les types d'écrans.

## Liens du Projet
- Site web en ligne (GitHub Pages) : https://mohamed408512.github.io/elan.fitness/
- Suivi du projet (Trello) : https://trello.com/b/Dy7kmk1F/elanfitness

## Structure du Site
- Accueil (index.html) : Présentation globale de la salle, mise en valeur de la marque et incitation à l'action.
- À propos (propos.html) : Histoire de la salle, valeurs, engagements et présentation de l'équipe.
- Programmes (program.html) : Détail des cours (musculation, yoga, cardio, boxe) et formules d'abonnement.
- Contactez-nous (contact.html) : Formulaire de message fonctionnel, coordonnées complètes et citation motivante.

## Fonctionnalités et Améliorations
- Design Responsive : Prise en charge fluide de tous les formats d'écran (Mobile, Tablette, Desktop).
- Améliorations SEO : Intégration de balises meta descriptions ciblées, titres de pages uniques, attributs alt explicites sur l'ensemble des images et structure HTML sémantique.
- Expérience Utilisateur (UX/UI) : Indication visuelle de la page active dans le menu de navigation et transitions CSS pour une interaction agréable.
- Conformité et Normes : Respect des standards du W3C et intégration des bonnes pratiques d'accessibilité (WCAG).

## Technologies Utilisées
- HTML5 (Balisage sémantique)
- CSS3 (Flexbox, Media Queries, Animations et Transitions)
- Git & GitHub (Contrôle de version et hébergement GitHub Pages)

## Breakpoints Responsive
- Mobile : Jusqu'à 767px
- Tablette : De 768px à 1023px
- Petit écran d'ordinateur : De 1024px à 1279px
